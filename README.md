# Le développement logiciel à l'ère de l'IA

Supports du cours *Le développement logiciel à l'ère de l'IA* (Certificat IA, Télécom SudParis).

- `cours/` : les transparents de chaque cours, en PDF.
- `exercices/` : les exercices en Python, un dossier par cours (`cours1/`, `cours2/`, …).
  Les fichiers `demo_*.py` sont les démonstrations montrées en cours ; les autres sont des
  exercices à compléter (cherchez `TODO`).

Pour installer les outils nécessaires (Python, Ollama, les modèles), suivez
[`exercices/README.md`](exercices/README.md).

Ce dépôt est mis à jour au fil du cours : faites un `git pull` avant chaque séance.
